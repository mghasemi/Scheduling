========================================
Appendix A: Preemptive Model
========================================

(4 to 14), for 50 different random scenarios according to the Perimeter data.

ASA for all 30-minutes timeslots with 95% confidence intervals are presented below.
Moreover, the active time (utilization) for the given number of evaluators is also
presented.
